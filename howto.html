01

Install & account

2 minutes
  • Install from the Chrome Web Store (or Load unpacked while testing).
  • Open the extension → Sign up or Log in (email or Google).
  • Accept the Terms before generating.
  • New accounts get a short Ultimate trial — plan timer badge shows time left.
02

API key (required)

Gemini free works
  • Open Settings (gear) and add a Gemini key (or OpenAI / Anthropic / xAI).
  • Free Gemini key: Google AI Studio.
  • Click Test connection until you see success.
  • Switch models anytime — generation uses the active provider + your custom prompt slot if set.
Without a valid key, Start AI Listing cannot call the model. Test once, then you’re set.
03

Generate a listing

Core flow
Open listing page → Green detect banner → Tone + competitors → Start AI Listing → Review power cards → Accept & Autofill
  • Open a listing edit page on Flipkart Seller Hub, Meesho Supplier, or Amazon Seller Central.
  • Banner turns green: … listing page detected.
  • Optional: Seller tone — balanced, creative, generic, reseller, premium, or max search.
  • Optional: paste 1–5 competitor links → Use these links (research only when links are present).
  • Press ✦ Start AI Listing. Watch the thinking animation (images → trends → writing).
  • While the draft is open, tone + competitor panels hide so you focus on the result. They return after autofill.
  • Always read title & description twice before marketplace submit.
Retail default: On Meesho / Flipkart / Amazon the AI writes for end-buyers. It will not force “wholesale” unless photos clearly show multipacks or cartons.

05

Accept & Autofill

Clears · then writes
  • Edit any field in the review form if you want, then press Accept & Autofill.
  • The extension clears existing values (text, dropdowns, keyword pills) and writes the new AI content — it does not leave stale choices.
  • After autofill you get a post-autofill checklist: what was filled vs what to still check on the page.
  • Seller tone + competitor panels come back so you can start the next product.
  • Flipkart: Model Name stays ≤ 80 characters. Meesho: title + description focus (no keyword field).
Reload the marketplace tab after updating the extension so content scripts pick up the new clear-and-fill logic.
06

Scan & score + stored improvements

Other features
  • Open Other features → Scan & score listing.
  • AI audits the current page (Seller Lens–style language on Flipkart; demand language elsewhere).
  • You get score, fixes, insights, keyword ideas.
  • Save improvement for next listing stores fixes under a product name.
  • On the next generate, pick one saved item. It is removed after a successful autofill.

08

Pro tips for visibility & orders

Do this every time
  • Images first — Meesho ≤4, Flipkart ≤6. Bright hero + detail beats a long title.
  • Fill filters — empty attributes cost search views more than weak adjectives.
  • Paste competitors when you can — gap card becomes specific instead of generic.
  • Price near the band — perfect copy at the wrong price still stalls.
  • Never invent specs — HSN, material, size only if true in photos / your knowledge.
  • Submit only after checklist — yellow “check on page” items hurt rank if left empty.
Visibility and orders start after the marketplace approves the listing (often hours to a few days). The extension maximises listing quality — it does not control platform ranking clocks.
