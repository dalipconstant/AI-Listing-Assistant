How to use AI Listing Assistant

Step-by-step guide for sellers on Flipkart, Meesho, Amazon, and more.

1. Install & account

  • Install from the Chrome Web Store (or Load unpacked while testing).
  • Open the extension → Sign up or Log in (email or Google).
  • Accept the Terms before continuing.
  • New accounts get a short Ultimate trial.

2. API key (required)

  • After first login, set a Gemini (free) or other provider key in Settings.
  • Get a free Gemini key: Google AI Studio.
  • Use Test connection until you see a green success state.
  • You can switch models/providers in Settings anytime.

3. Generate a listing

  • Open a listing edit page on Flipkart Seller Hub, Meesho Supplier, or Amazon.
  • Open the extension — the banner should turn green: … listing page detected.
  • Optional: set Seller tone (balanced / generic / reseller / premium / search).
  • Optional: paste competitor links → Use these links.
  • Press Start AI Listing → review the draft → Accept & Autofill.
  • Always review fields at least twice before submitting on the marketplace.

4. Scan & score

  • Open Other features → Scan & score listing.
  • AI audits like Seller Lens (Flipkart) or search-demand language (other sites).
  • You get a score, fixes, insights, and keyword ideas.
  • Save improvement for next listing stores those fixes under a product name.
  • On the next generate, select that saved item (one at a time). It is cleared after one successful autofill.

5. Plans & codes

  • Open Plan from the extension to subscribe via Razorpay.
  • Discount/gift codes can be redeemed on the Plans page when available.

6. Tips

  • Flipkart Model Name must stay under 80 characters (extension enforces this).
  • Meesho: focus on title + description (no keyword field).
  • AI only describes what images support — never invent HSN/material/size.
  • Need help? Email supportailistingassistant@gmail.com.
